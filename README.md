# Curso Software Asistido por IA

Repositorio académico del curso Software Asistido por IA.

Este repositorio contiene material académico, documentación, evidencias y entregables del curso.

El código fuente real de EcoWash vive en un repositorio Git separado. La aplicación no se duplica aquí.

## Material del curso

La carpeta `00-material-curso/` contiene rúbricas, guías, apuntes y referencias generales del curso.

## Proyecto EcoWash

La carpeta `01-proyecto-ecowash/` contiene documentación, diseños, evidencias y enlaces relacionados con EcoWash.

El código real del proyecto se mantiene fuera de este repositorio académico.

## Tarea 1

La carpeta `tarea-01/` contiene documentos de análisis, historias de usuario y entregables de la primera tarea.

## Tarea 2

La carpeta `tarea-02/` contiene el material de diseño de software y espacio preparado para investigación complementaria.

## Tarea 3 — Tests POM y TDD

La carpeta `tarea-03-tests/` contiene la investigación, análisis, evidencias, prompts y entregables sobre pruebas.

Esta tarea analiza pruebas reales del proyecto EcoWash, pero el código de la aplicación no se duplica aquí.

## Skills

La carpeta `skills/` conserva documentación y evidencias relacionadas con skills usados durante el curso.
