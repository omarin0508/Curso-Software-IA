# Non-Functional Requirements

## Introduction

This document defines the quality requirements for the web application used to administer a carpet and upholstery cleaning service. These requirements describe how the system should perform, protect information, remain available, and support future maintenance beyond its core functional behavior.

| ID | Requirement | Category | Priority |
| --- | --- | --- | --- |
| NFR-01 | The system shall require user authentication before accessing administrative functions. | Security | High |
| NFR-02 | The system shall display pages within a maximum of three seconds under normal operating conditions. | Performance | High |
| NFR-03 | The system shall be available during business operating hours with high reliability. | Availability | High |
| NFR-04 | The user interface shall be intuitive and easy to use for customers and staff members. | Usability | High |
| NFR-05 | The system shall be compatible with modern desktop and mobile web browsers. | Compatibility | Medium |
| NFR-06 | The system shall protect customer information from unauthorized access. | Security | High |
| NFR-07 | The system shall maintain data integrity during service request processing. | Reliability | High |
| NFR-08 | The system shall allow future expansion without affecting existing functionality. | Maintainability | Medium |

## Requirement Details

NFR-01 ensures that only authorized users can access administrative functions such as managing service requests, customer records, schedules, and internal business information.

NFR-02 establishes a performance expectation so that users can navigate the application efficiently, with pages loading within three seconds under normal operating conditions.

NFR-03 requires the system to remain reliably available during business operating hours, allowing customers and staff members to use the application when the service is active.

NFR-04 ensures that the application interface is clear, intuitive, and easy to use for both customers requesting services and staff members managing operational tasks.

NFR-05 requires the application to work correctly on modern desktop and mobile web browsers, supporting access from common devices used by customers and employees.

NFR-06 protects customer information, including contact details, service addresses, and request history, from unauthorized access or exposure.

NFR-07 ensures that service request data remains accurate and consistent throughout processing, including creation, updates, scheduling, and status changes.

NFR-08 supports future growth by requiring the system to allow new features, modules, or service options to be added without disrupting existing functionality.

## Summary

These non-functional requirements ensure the quality, security, availability, and maintainability of the system.
